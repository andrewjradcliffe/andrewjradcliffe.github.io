#+TITLE: andrewjradcliffe.github.io

Source for https://andrewjradcliffe.github.io/ — a multi-page site
exported from Org via =org-publish=. =main= is source-only; the built
site lives under =public/= (gitignored) and is published by CI.

The full design specification and implementation plan live in
[[file:notes/spec.org][=notes/spec.org=]].

* Build
The site builds with =emacs --batch= driving =site/publish.el=.

| Target         | Effect                                              |
|----------------+-----------------------------------------------------|
| =make publish= | Build the whole site into =public/=.                |
| =make serve=   | Build, then serve =public/= on http://localhost:8000 |
| =make clean=   | Remove =public/= and Org timestamp cache.           |

Requires Emacs (with Org) on =PATH=. Pinned versions for reproducible
builds are documented here once CI is wired (Stage 4).

* Deploy
Pushes to =main= are built (validated) by CI but *not* published.
The live site is deployed only when a =v*= tag is pushed, so the
site flips once, complete.

* Adding content
- *Blog post*: =make new-post t="Some title"= scaffolds a dated draft
  under =src/blog/= (Stage 2).
- *Project*: append one entry to =src/projects.org= (Stage 1).
