* How to use this document
This is the working spec for redesigning https://andrewjradcliffe.github.io/.

It has three parts:
- *Part I — Proposed design.* Opinionated proposals for theme, layout,
  typography, content rearrangement, and the three new components
  (blog, open-source projects, pre-prints). Read this first; the
  questions hang off it.
- *Part II — Open questions.* One nested list, organized by spec
  section and by each bullet within it. Every question has a stable ID
  (=Qn.m=), a /Recommendation/ (my default if you don't care), and an
  =ANSWER:= slot. To go fast: reply "defaults for §X" and I'll take the
  recommendations.
- *Part III — Implementation plan.* Deliberately empty. Per your
  instructions, I will not write it until the questions are answered.
  It will be granular: each leaf bullet ≤10 min and independently
  verifiable.

Conventions: =§= = section. "the Zone" = the proposed dark theme.
Reference shorthand: STALKER / SOLARIS / MWQ (/The Man Without
Qualities/) / SISYPHUS / EMACS / LINUX.

*Thesis.* A dark, low-contrast "terminal opened inside the Zone":
JuliaMono throughout, oxidized-metal accents on near-black, Emacs
modeline + shell-prompt chrome, copy that is terse and lucidly
absurdist. Restraint in motion (Tarkovsky long takes): slow fades, no
bounce, nothing autoplaying.

** Information architecture (proposed)
Move from one scroll to a small multi-page "zone." Proposed sitemap:
- =/= — Landing. Epigraph + a one-line identity + a terminal-style
  index (links to the four areas). Keeps the current tagline energy.
- =/projects/= — Open-source work, regrouped /by language → by kind/
  (see §I.6). Absorbs today's "Julia packages", "Rust crates", "Rust
  applications".
- =/writing/= — Pre-prints + papers. Absorbs today's "Writing" (GCM/LCM).
- =/blog/= — Index of essays; each post its own page.
- =/blog/<slug>/= — Individual posts.
- =/about/= — (optional) Identity, colophon, contact, /uses/.
- =/feed.xml= — RSS/Atom for the blog.

** Build pipeline (proposed)
Recommend =org-publish= (=org-publish-project-alist= in a committed
=publish.el=), driven by =emacs --batch=. Rationale: keeps everything
Org + Emacs native (on-theme), gives multi-page + sitemap + RSS + asset
copying for free, and can be wired to a GitHub Actions job or a local
=make publish=. Single shared =setupfile.org= / =HTML_HEAD= for the
theme. Alternative considered & rejected for vibe reasons: Hugo/Zola.

** Theme — color (proposed)
Default dark theme "the Zone" (CSS custom properties):
- =--bg=        #0e1110  (near-black, faint green of the Zone at dusk)
- =--bg-alt=    #161a18  (panels, code blocks, modeline)
- =--fg=        #c8c2b6  (aged paper / dust)
- =--fg-muted=  #7c8079  (lichen grey-green; metadata)
- =--amber=     #c8923d  (ochre/sepia warmth; headings, prompt)
- =--rust=      #a44f3e  (oxidized iron; emphasis, visited links)
- =--teal=      #4e8d86  (Solaris ocean; links)
- links =--teal=, hover =--amber=; selection in =--rust= at low alpha.
Optional alternate light theme "Sepia" (Stalker's framing scenes):
=--bg= #e8e0cf, =--fg= #2a2622, accents darkened. Toggle persists in
=localStorage=.

** Typography (proposed)
JuliaMono everywhere (you said "preferably JuliaMono where
applicable"), self-hosted as subset =woff2= for performance, with a
monospace system fallback. Headings = JuliaMono heavier weight +
=--amber=. Math via MathJax (kept), tuned to sit with JuliaMono.
